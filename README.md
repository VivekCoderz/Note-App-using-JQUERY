# My Notes – jQuery Notes App

Live: https://myynotess.netlify.app/

A small notes app built with HTML and jQuery (all styling is applied from jQuery).

## Features
- Add a note with a title and content (both required)
- Edit a note: it is loaded back into the form so you can change it and add it again
- Delete a note
- Live search across note titles and content

Notes are kept in memory only, so they are cleared when the page is refreshed.

## Run
Open `index.html` in a browser. jQuery 3.7.1 loads from the jQuery CDN.

## Files
- `index.html`: page markup
- `scripti.js`: app logic and styles
